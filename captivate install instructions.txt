update cdk:
sudo npm install -g aws-cdk@latest


run npm install for all lambdas
find . -name "package.json" \
  -not -path "*/node_modules/*" \
  -not -path "./package.json" \
  -not -path "./cdk.json" \
  | while read f; do
      dir=$(dirname "$f")
      echo "Installing in $dir..."
      (cd "$dir" && npm install)
  done



to create a new deployment:

mac VS Code terminal:
  ./build-s3-dist.sh cap-deployment-staging us-east-1 v1.0.0
windows VS Code terminal
  bash build-s3-dist.sh cap-deployment-staging video-on-demand-on-aws v1.0.0



  set CDK_DEFAULT_ACCOUNT=909442478174 && set CDK_DEFAULT_REGION=us-east-1 && npx cdk synth 2>&1


create regional deploy bucket
aws s3 mb s3://cap-deployment-staging-us-east-1 --region us-east-1

check status of an update
aws cloudformation describe-stacks   --stack-name video-on-demand-2026   --query "Stacks[0].StackStatus"   --region us-east-1


upload to bucket

global
aws s3 cp global-s3-assets/ s3://cap-deployment-staging/video-on-demand-on-aws/v1.0.0/ --recursive --acl bucket-owner-full-control

regional
aws s3 cp regional-s3-assets/ s3://cap-deployment-staging-us-east-1/video-on-demand-on-aws/v1.0.0/ --recursive --acl bucket-owner-full-control

deploy with cdk and include branch
cd source/cdk
BRANCH=staging npx cdk deploy --parameters AdminEmail=kmcgurn@captivate.com


update lambda:
  change encode's index.js locally.
  run BRANCH=staging npx cdk deploy --parameters AdminEmail=kmcgurn@captivate.com
